# PdfTool

Десктопное приложение для Windows для работы с PDF: деление, склейка, перестановка, поворот и удаление страниц. Работает полностью офлайн, использует только бесплатные библиотеки под MIT и Apache-2.0.

## Что умеет

- **Открыть PDF** кнопкой, по Ctrl+O или перетаскиванием файла в окно. Можно передать путь в командной строке: `PdfTool.exe файл.pdf`.
- **Последние файлы:** стрелка ▾ у кнопки «Открыть» показывает 10 последних файлов. Список хранится в `%AppData%\PdfTool\recent.txt`.
- **Просмотр страницы крупно:** двойной клик (или Enter) по миниатюре. ← → листать, + − и Ctrl+колёсико масштаб, 0 по размеру окна, Esc закрыть.
- **Миниатюры страниц** в сетке с номерами. Рендер идёт в фоне, поэтому окно не зависает даже на файлах в 100+ страниц.
- **Выделение** кликом, Ctrl+кликом, Shift+кликом, кнопкой «Выделить всё» или по Ctrl+A.
- **Перестановка** страниц перетаскиванием мышью.
- **Поворот** выбранных страниц на 90° влево или вправо.
- **Удаление** выбранных страниц (Delete).
- **Отмена** последнего действия (Ctrl+Z). Работает для удаления, поворота, перестановки и добавления.
- **Деление:**
  - по диапазонам: в нижнее поле вводится строка вида `1-3, 4-7, 8-10`, на каждый диапазон создаётся отдельный файл;
  - каждая страница в отдельный файл;
  - выбранные страницы в один новый PDF.
  
  Имена файлов: `ИмяИсходного_1-3.pdf`, `ИмяИсходного_4-7.pdf`, `ИмяИсходного_5.pdf`. Номера страниц считаются по текущему порядку в окне, то есть с учётом перестановок и удалений.
- **Склейка:** «Добавить PDF» дописывает страницы другого файла в конец документа, дальше их можно переставлять. Можно добавить сразу несколько файлов или перетащить их в окно.
- **Сохранить** (Ctrl+S) и **Сохранить как** (Ctrl+Shift+S).
- **Очистить** (Ctrl+W): закрыть текущий PDF и вернуться к пустому окну. Файл на диске не трогается.
- **Меню «Инструменты»:**
  - **Подпись / печать:** выбираешь фото или скан подписи, перетаскиваешь её мышкой на странице, размер меняешь за синий уголок. «Убрать белый фон» делает бумагу прозрачной, поля обрезаются автоматически. Подпись можно поставить на эту страницу, на выбранные или на все. Она видна на миниатюрах, отменяется по Ctrl+Z, при повороте страницы поворачивается вместе с ней и попадает в файл при сохранении. Кнопка **«Обрезать / стереть…»** убирает лишнее с картинки: «Круг» оставляет только круглую печать, «Рамка» оставляет выделенную часть, «Ластик» стирает мелочи. Для цветных печатей есть **«🎨 Только цветное»**: убирает весь чёрный и серый текст документа, попавший в печать, и остаётся синяя печать. Ещё есть **«Умный ластик»**, который стирает только чёрное, не трогая цветное, и выбор строгости («Мягко», «Средне», «Строго»). На чёрно-белых сканах цветовой фильтр не работает: печать и текст там одного цвета. Где чёрная буква лежала поверх линии печати, остаётся небольшой пробел. Есть «Отменить шаг» (Ctrl+Z) и «Сначала». Последние 5 картинок подписей запоминаются. Есть пункт «Убрать подписи с выбранных страниц». Это картинка подписи, а **не** электронная цифровая подпись (ЭЦП).
  - **Сжать PDF:** крупные картинки и сканы уменьшаются примерно до 150 DPI и пережимаются в JPEG (серые остаются серыми), текст не трогается. Результат сохраняется новым файлом, программа показывает «было → стало». Если уменьшить не удалось, файл не создаётся.
  - **Нумерация страниц:** где ставить (внизу или вверху, по центру или сбоку), вид («1», «Стр. 1», «1 из 10» …), с какого числа начинать, размер шрифта. Номер ставится правильно и на повёрнутых страницах. Сохраняется новым файлом.
  - **Страницы → JPG / PNG:** выбранные страницы (или все) сохраняются картинками 150 DPI: `Имя_стр1.jpg`, `Имя_стр2.jpg` …
  - **Картинки → PDF** и **Word → PDF** (см. ниже).
- **Картинки → PDF** (`.jpg`, `.png`, `.bmp`, `.gif`, `.webp`): каждая картинка становится страницей A4, ориентация листа выбирается по картинке. Фото с телефона разворачиваются по EXIF. Несколько картинок, перетащенных сразу, собираются в один PDF по порядку имён, как в Проводнике. PDF сохраняется рядом с первой картинкой.
- **Документы Word → PDF** через установленный Microsoft Word (`.docx`, `.doc`, `.docm`, `.rtf`, `.odt`). Программа сама распознаёт документ Word, если его:
  - перетащить в окно;
  - выбрать через «Открыть» или «Добавить PDF»;
  - выбрать кнопкой «Word → PDF».

  PDF сохраняется рядом с документом под тем же именем (если такой файл уже есть, программа спросит) и сразу открывается. Его можно редактировать и склеивать с другими PDF. Без установленного Word программа покажет понятное сообщение.

### Безопасность файлов

- Исходный файл никогда не перезаписывается без подтверждения. Существующие файлы при делении тоже.
- Открытый PDF загружается в память и на диске не блокируется: его можно открыть в другой программе или перезаписать.
- Запись идёт через временный файл с последующей заменой. Если при сохранении что-то пошло не так, целевой файл не пострадает.
- Понятные сообщения об ошибках: повреждённый PDF, PDF с паролем, файл занят другой программой, нет доступа, папка не найдена.
- Если документ изменён, при закрытии или открытии другого файла приложение предложит сохранить изменения.

## Сборка

Нужен .NET SDK 8 или новее (проект нацелен на `net8.0-windows`, для запуска нужен .NET Desktop Runtime 8).

```bash
# сборка и тесты
dotnet build PdfTool.sln -c Release
dotnet test PdfTool.sln

# готовая папка с программой → dist\PdfTool.exe
dotnet publish src/PdfTool/PdfTool.csproj -c Release -r win-x64 --self-contained false -o dist
```

Чтобы программа запускалась без установленного .NET, укажите `--self-contained true` (папка станет больше).

### Установщик

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

Скрипт прогоняет тесты, публикует self-contained версию в `publish\` и собирает `dist\PdfTool-Setup-1.0.0.exe` через [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`). Описание установщика лежит в `installer\PdfTool.iss`; этот файл и скрипт сохранены в UTF-8 с BOM.

Что делает установщик:
- ставит программу в `%LocalAppData%\Programs\PdfTool`, права администратора не нужны, .NET на компьютере не нужен;
- создаёт ярлык в «Пуск» и, по желанию, на рабочем столе;
- по желанию добавляет PdfTool в «Открыть с помощью» для PDF, Word и картинок (только для текущего пользователя, программа по умолчанию не меняется);
- при удалении всё убирает, но `%AppData%\PdfTool` (последние файлы, подписи) сохраняет.

Версия задаётся в `installer\PdfTool.iss` (`AppVersion`) и в `src\PdfTool\PdfTool.csproj` (`Version`).

## Структура

```
PdfTool.sln
├── src/PdfTools.Core/          библиотека: вся логика PDF, без UI
│   ├── PdfDocumentModel.cs     модель: список страниц (исходник, номер, поворот) + стек отмены
│   ├── PdfSource.cs            исходный PDF, загруженный в память
│   ├── PdfPageEditor.cs        перестановка, поворот, удаление, сохранение
│   ├── PdfSplitter.cs          деление по диапазонам / по страницам / выбранные
│   ├── PdfMerger.cs            склейка
│   ├── PageRangeParser.cs      разбор строки "1-3, 5, 7-10" с проверкой
│   ├── PdfRenderer.cs          миниатюры (PNG) через PDFium
│   ├── PdfOutput.cs            сборка нового PDF и безопасная запись на диск
│   ├── Stamp.cs                подпись на странице + перевод координат при повороте
│   ├── StampImage.cs           подготовка картинки подписи (убрать фон, обрезать)
│   ├── ImagePdfBuilder.cs      картинки → PDF (A4, поворот по EXIF)
│   ├── PdfImageExporter.cs     страницы → JPG/PNG
│   ├── PdfCompressor.cs        сжатие картинок внутри PDF
│   ├── PdfPageNumberer.cs      нумерация страниц (с учётом поворота)
│   ├── WordConverter.cs        Word → PDF через установленный Word (COM, dynamic, без PIA)
│   └── PdfToolException.cs     ошибки с понятным текстом на русском
├── src/PdfTool/                WinForms-приложение, только интерфейс
│   ├── MainForm.cs             логика окна
│   ├── MainForm.Convert.cs     Word и картинки → PDF (меню, «Открыть», перетаскивание)
│   ├── MainForm.Tools.cs       меню «Инструменты», последние файлы, просмотр, «Очистить»
│   ├── PageViewerForm.cs       просмотр страницы крупно
│   ├── PageNumberDialog.cs     настройки нумерации
│   ├── StampPlacementForm.cs   окно установки подписи
│   ├── StampCanvas.cs          страница с перетаскиваемой подписью
│   ├── StampEditForm.cs        обрезка подписи рамкой/кругом, ластик
│   ├── RecentFiles.cs          список последних файлов
│   ├── MainForm.Ui.cs          создание элементов окна
│   └── ThumbnailView.cs        сетка миниатюр, перетаскивание, фоновый рендер
└── tests/PdfTools.Core.Tests/  xUnit-тесты для Core
```

Правки страниц не трогают PDF сразу: модель хранит список ссылок на страницы, а реальный файл собирается только при сохранении или делении. Поэтому отмена работает мгновенно, а исходник остаётся нетронутым.

## Про Microsoft Word

Word запускается отдельным скрытым экземпляром: открытые у пользователя документы программа не трогает. Принудительно Word закрывается, только если не отвечает 5 минут. Иначе после принудительного закрытия Word при следующем запуске спрашивает «Запустить в безопасном режиме?», а скрытая автоматизация на этом вопросе виснет.

Конвертации PDF → Word в программе нет: бесплатными средствами не получается сохранить вёрстку на уровне онлайн-сервисов.

Тесты, которые запускают настоящий Word, по умолчанию пропускаются. Включить их: `set PDFTOOL_WORD_TESTS=1` перед `dotnet test`.
